# 牛客运营以插件为主

用户要求找帖、读评论和发送回复主要依赖 data collector，减少 Browser Use 快照和重复定位消耗。现有版本只完成正文采集、草稿和台账，实际操作链路仍有缺口。

## 本轮交付

- `nowcoder ops search --query QUERY --limit N`：复用已有 Nowcoder JSON 最新搜索；只输出有限条标题、链接、时间和短摘，排除已回复来源。
- `nowcoder ops context --id ID`：由已连接扩展打开自己拥有的后台标签页，读取推荐评论、楼中楼及楼主回复；保存私有快照，返回正文、图片引用和精简评论。报告显示总数、实际读取数、是否完整及分页边界。
- `nowcoder ops publish --id ID --revision N --key KEY --send`：发送已经存入该条记录的主稿；明确发送参数、当前修订号、正文身份和幂等键缺一不可。返回真实评论链接并更新台账。
- Agent 继续负责判断需求、理解图片和写回复，插件执行确定性页面操作。登录、验证码和站点限制交给用户，不换浏览器或接口绕过。

## 实现选择

沿用当前 Bridge HTTP 认证和固定扩展 WebSocket。搜索复用已有结构化 provider；评论和发送在扩展自建标签页内操作可见 DOM，不猜写入接口，不导出 Cookie 或令牌。RPC 只允许规定动作及牛客规范帖子 URL，不提供任意脚本/请求执行入口。

扩展返回纯数据；原始 DOM 不进入日常 CLI 输出。图片保留来源引用，无法从文字确认的内容如实标记，Agent 可按需读已采集图片。

发布尝试在点击之前持久化。重复键不能再次发送；一条来源存在未决尝试时，新键也不能绕过。超时或连接中断导致结果不确定时，只允许核验，不能自动重试点击。只有读到新出现、正文相符的真实评论链接才记录为已回复。

## 约束

直接在 master 工作，保留其他任务的修改；本轮完成后统一补丁版本至 0.4.58。采集只落本机，运营快照和回执不进公共面经/收件箱。没有自动批量发评、私信或定时发布。自建标签页关闭或转为必要的用户接管页；用户标签页不刷新、不覆盖草稿。发送期间阻止扩展自动重载及 Bridge 自动退出。

## 验收

精简搜索和评论快照通过 CLI 获取；过期草稿、错误来源、无授权参数、重复发送、限制页面、提交后回执丢失均有行为测试。类型检查、完整测试、打包和端到端检查通过。新版本及运行时构建一致后，使用插件对已经选定的两篇帖子各发一条，分别核对链接并记录；本轮发送总数为两条。
