# Nowcoder operation-candidate framework

This mode is deliberately private and preparatory. It may collect and organize timely, popular, or controversial Nowcoder topics, but it must not generate final Xiaohongshu copy, publish posts, or call social-platform APIs.

For explicitly authorized private product-user research, use the separate `nowcoder research` command and the exact private manifest described in [docs/nowcoder-hot-materials.md](../../../../docs/nowcoder-hot-materials.md). This purpose reuses extension detail capture but does not require, modify, or replace the public interview history. `nowcoder run` remains the path for interview/knowledge publication requests. Freeze current hot observations separately from latest search results, retain the raw input, and consume only the returned completed research run. Failed or incomplete runs remain preserved; never pool them to meet a quota. Private research has no delivery IDs, public commit, or publication workflow requirement.

Write private outputs under `_inbox/_reports/operation-topics-YYYY-MM-DD.md` with a sibling JSON manifest. Each candidate must include:

- stable source URL, title, author when public, and observed date;
- measurable popularity signals and when they were observed;
- the disputed question and a fair summary of both sides;
- relevance to Agent Journey’s audience;
- freshness/expiry window;
- verification status and missing evidence;
- privacy, defamation, copyright, and platform-compliance risks;
- recommendation: pursue, watch, or reject, with a short reason.

Deduplicate by canonical URL and controversy/topic cluster. Separate facts from inference. Remove personal identifiers that are not necessary to understand the topic. Keep all outputs private and untracked unless the user explicitly promotes this framework into a later publishing iteration.

For framework-only work, completion means the framework and report contract exist. An authorized research request requires its exact completed research run and the requested evidence-based private report. A request to actually publish operation content requires a separate product decision and authorization.
